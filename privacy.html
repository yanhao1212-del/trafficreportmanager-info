隱私權政策

草稿修訂日期：2026 年 10 月 22 日｜適用程式：TrafficReportManager

1. 適用範圍

TrafficReportManager 是供家庭私人使用的本機交通違規檢舉通知管理及指定平台驗證信清理工具。本政策說明本機程式如何存取、使用及保存由帳號持有人授權的 Google 使用者資料，以及介紹網站的資料範圍。

2. 存取哪些 Gmail 資料

  • 案件管理功能使用 Gmail 唯讀權限，讀取相關通知所需的郵件識別碼、寄件來源標頭、通知時間與必要文字欄位，例如案件編號、車牌、違規日期、機關來源及處理結果。
  • 驗證信清理功能使用另行授權的 Gmail 修改權限，檢查候選郵件的寄件來源、驗證資訊、主旨、標籤、實際收信時間及固定驗證格式。
  • 解析所需的純文字或 HTML 本文僅在本機記憶體處理，不另存完整郵件本文，不下載附件或圖片。必要案件欄位與審核證據可保存於本機資料庫及報表。
  • 程式不保存案件查詢密碼或驗證網址中的識別碼，也不將驗證碼寫入執行紀錄。

3. 如何使用資料

資料僅用於使用者指定的案件配對、結果整理、人工審核、統計報表、去重與中斷續傳，以及經核准的驗證信清理。程式不因多封通知重複計算同一案件，人工決定及通知歷史予以保留。

清理僅限已核准的基隆交通檢舉平台驗證信：需通過精確來源與固定格式核對，且 Gmail 實際收信時間嚴格超過 2 小時。符合條件者僅移至 Gmail 垃圾桶，不由程式永久刪除；垃圾桶仍適用 Gmail 自身的保存與自動刪除規則。

4. 資料保存與保護

必要案件欄位、通知識別碼與原信連結、人工決定、審核歷史、統計報表及匿名化執行計數保存於使用者電腦。案件管理與清理功能使用不同的本機授權儲存位置；清理專用 Token 使用 Windows 使用者範圍加密保護。

資料持續保存至使用者決定移除；程式不會因清理驗證信而刪除案件資料。備份與雲端資料夾同步取決於使用者自己的系統設定，若本機資料夾受同步服務管理，其檔案可能依該服務設定同步。

使用者應保護電腦帳號、限制資料夾存取並妥善管理備份。程式的來源、授權或完整性檢查失敗時會停止，不自動擴大清理範圍。

5. 分享與限制使用

程式向 Google Gmail API 發出執行使用者功能所需的請求；不將真實郵件本文、案號、車牌、憑證或其他敏感資料傳送給外部 AI。程式不出售 Google 使用者資料，不將其用於廣告、使用者側寫，或訓練通用 AI／機器學習模型。

除使用者自行匯出、分享或設定的檔案同步外，程式不提供向第三方公開案件資料的功能。TrafficReportManager 對 Google API 所取得資訊的使用與轉移，應遵守 Google API Services User Data Policy，包括其 Limited Use 要求。

6. 撤銷授權與刪除資料

使用者可在 Google 帳戶的第三方連線管理移除應用程式的存取權。撤銷後程式無法繼續存取 Gmail，排程遇到授權失效時會停止。

撤銷授權不會自動刪除已儲存的本機資料。若要完整移除，請先停用 Windows 排程，再由管理者協助刪除指定的本機授權檔、資料庫、報表、審核檔及其備份；自行同步的副本也須另行處理。刪除本機資料不代表刪除 Gmail 原始郵件。

7. 介紹網站

本草稿網站不提供登入、表單、案件上傳或 Gmail 連線，不使用分析追蹤腳本，也不載入第三方字型。未來公開託管時，託管業者可能記錄必要的連線及安全日誌；發布前將依選定服務補充說明。

8. 政策更新與聯絡

管理者會在功能或資料處理方式變更時更新政策及修訂日期。若有疑問或資料處理需求，私人使用者可直接聯絡程式管理者，或使用 Google OAuth 同意畫面的支援電子郵件；公開聯絡方式須在發布前確認。

這是本機草稿，並非已部署或已經 Google 驗證的政策頁面。不能將本機檔案路徑填入 Google Cloud 作為公開政策網址。
